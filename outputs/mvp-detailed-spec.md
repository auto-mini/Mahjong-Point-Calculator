# 리치마작 부수/점수 계산 웹앱 MVP 상세 설계서

작성일: 2026-07-04

## 1. 목표

실제 작탁에서 휴대폰으로 빠르게 사용하는 4인 리치마작 계산기.

MVP의 핵심 목표는 다음과 같다.

- 작혼 4인 일반게임 기준으로 일반역, 도라, 부수, 최종 점수를 자동 계산한다.
- 사용자는 역/부수 해석 후보를 고르지 않는다.
- 앱은 가능한 해석 중 최고 점수 결과 하나를 표시한다.
- 역만은 점수 계산하지 않고 감지 시 부수 계산 대상 아님을 표시한다.
- 백엔드 없이 정적 웹앱으로 동작한다.
- 모바일 우선 UI로 만든다.

MVP의 비목표는 다음과 같다.

- 삼마 지원
- 국사무쌍/역만 점수 계산
- 유국만관, 노텐 벌부, 쵼보, 책임지불, 다중 론 처리
- 로컬역 지원
- 계정/서버/DB/동기화
- 작혼 이미지/상표/에셋 복제

## 2. 기준 룰

작혼 4인 일반게임/단위전 계열 룰을 기준으로 한다.

- 쿠이탕 있음
- 후로 감산 있음
- 연풍패 머리는 4부
- 핑후 쯔모는 20부
- 치또이는 25부 고정
- 절상만관 없음
- 5판 이상은 부수 무관
- 13판 이상은 카조에역만으로 표시
- 적도라는 5만/5통/5삭 각 1장
- 깡도라/깡우라도라 있음
- 암깡 깡도라는 즉시 적용
- 명깡/가깡 깡도라는 후공개 기준

## 3. 사용자 입력

### 3.1 항상 입력

- 마지막 깡 직후 화료 여부
- 손패 완성형
- 화료패
- 론/쯔모
- 장풍: 동/남/서/북
- 자풍: 동/남/서/북
- 본장 수
- 도라 표시패

고정값:

- 공탁 리치봉 수는 입력하지 않고 0으로 고정

### 3.2 조건부 입력

리치 또는 더블리치가 선택된 경우:

- 우라 표시패

상황역:

- 리치
- 더블리치
- 일발
- 해저로월
- 하저로어
- 영상개화
- 창깡

도라/우라 입력 전 항상 먼저 묻는다.

> 마지막 깡 직후에 화료했나요?

아니오:

- 도라 표시패 입력 단계로 바로 이동한다.
- 리치/더블리치가 아니면 문구: "도라 표시패를 순서대로 모두 입력하세요."
- 리치/더블리치면 문구: "도라 표시패와 우라 표시패를 순서대로 모두 입력하세요."

예:

- 앱이 이미 입력된 화료 방식/상황역/깡 정보로 해당 마지막 깡의 도라/우라 인정 여부를 판단한다.
- 깡이 2개 이상이고 암깡과 명깡/가깡이 섞여 있으며, 마지막 깡의 정체에 따라 인정 여부가 달라지는 경우에만 추가 질문한다.
- 마지막 깡이 상대의 깡이면 내 손패 안에 깡쯔가 없어도 될 수 있다. 이 경우 론/창깡/영상개화 정보로 판단한다.

추가 질문:

> 쯔모 직전 깡 종류를 선택해주세요.

선택지는 `안깡` / `안깡 아님`으로 표시한다.

판단 후 문구:

리치/더블리치가 아닌 경우:

- 인정: "해당 깡으로 인한 도라는 인정됩니다. 포함하여 입력해주세요."
- 미인정: "해당 깡으로 인한 도라는 인정되지 않습니다. 제외하고 입력해주세요."

리치/더블리치인 경우:

- 인정: "해당 깡으로 인한 도라와 우라도라는 인정됩니다. 포함하여 입력해주세요."
- 미인정: "해당 깡으로 인한 도라와 우라도라는 인정되지 않습니다. 제외하고 입력해주세요."

### 3.3 손패 입력 방식

최종 완성형 전체를 입력한다.

- 일반 손: 최종 14장
- 깡 포함 손: 14장 + 선언된 깡 수
- 화료패는 이 최종 입력 안에 포함된 패 중 하나로 별도 지정한다.
- 화료패를 별도 추가 패처럼 입력하지 않는다.

기본 흐름:

1. 37종 패 버튼 중 하나를 누른다.
2. 그 패를 포함할 수 있는 후보를 표시한다.
3. 사용자는 후보를 골라 입력한다.
4. 몸통 후보에는 후로 여부만 선택한다.
5. 닫힌 순자/커쯔/머리는 입력 편의용 묶음일 뿐, 계산 시 다시 풀어서 자동분해한다.

37종:

- 만수 1~9, 적5만
- 통수 1~9, 적5통
- 삭수 1~9, 적5삭
- 동/남/서/북/백/발/중

후보 예:

- 머리: 55
- 순자: 345, 456, 567
- 커쯔: 555
- 깡쯔: 5555

후로 여부:

- 순자 + 후로 ON = 명순자
- 순자 + 후로 OFF = 닫힌 순자 입력 묶음
- 커쯔 + 후로 ON = 명각
- 커쯔 + 후로 OFF = 닫힌 커쯔 입력 묶음
- 깡쯔 + 후로 ON = 명깡
- 깡쯔 + 후로 OFF = 암깡

고정 정보:

- 후로 ON 몸통은 고정한다.
- 암깡은 고정한다.
- 화료패는 고정한다.

재분해 대상:

- 후로 OFF 순자
- 후로 OFF 커쯔
- 머리
- 위 묶음에 포함된 모든 닫힌 패

같은 패 4장을 입력해도 사용자가 깡쯔로 지정하지 않으면 선언한 깡으로 보지 않는다.

## 4. 자동 계산 흐름

### 4.1 전처리

1. 입력된 모든 패를 정규화한다.
2. 적5는 해당 색의 5로도 계산하고, 적도라 1개로도 계산한다.
3. 후로 고정 몸통과 암깡을 분리한다.
4. 닫힌 입력 묶음을 패 풀로 합친다.
5. 화료패가 최종 손패 안에 있는지 검사한다.
6. 패 수량을 검사한다.

수량 제한:

- 같은 물리 패는 최대 4장
- 적5만/적5통/적5삭은 각각 최대 1장
- 일반 5와 적5를 합쳐 해당 색 5는 최대 4장
- 손패 + 도라 표시패 + 우라 표시패까지 합쳐 같은 패가 4장을 넘으면 계산불가
- 수량 초과 시 어느 패가 몇 장으로 초과됐는지 표시한다.

### 4.2 화료형 생성

후로 고정 몸통과 암깡을 제외한 닫힌 패 풀에서 가능한 해석을 생성한다.

지원 화료형:

- 일반형: 4몸통 + 1머리
- 치또이: 서로 다른 7종의 또이츠

제외:

- 국사무쌍
- 역만 전용 손패의 점수 계산

일반형 생성 시:

- 순자/커쯔/머리 가능한 모든 조합을 생성한다.
- 화료패가 어느 닫힌 조합에 들어갈 수 있는지 후보를 만든다.
- 후로 고정 몸통에는 화료패를 붙이지 않는다.
- 후보 목록은 사용자에게 기본 표시하지 않는다.

### 4.3 역만 감지

역만은 점수 계산하지 않는다.

명백한 역만이 감지되면 즉시 중단한다.

표시:

> 역만 손패입니다. 부수 계산 대상이 아닙니다.

감지 대상:

- 대삼원
- 사암각/사암각 단기
- 자일색
- 녹일색
- 청노두
- 소사희
- 대사희
- 사깡쯔
- 구련보등/순정구련보등

국사무쌍은 입력 방식에서 제외한다.

### 4.4 일반역 판정

역만 제외 일반역을 자동판정한다.

1판:

- 리치
- 일발
- 멘젠쯔모
- 탕야오
- 핑후
- 이페코
- 해저로월
- 하저로어
- 영상개화
- 창깡
- 동/남/서/북/백/발/중

2판:

- 더블리치
- 치또이
- 또이또이
- 삼암각
- 삼색동순
- 삼색동각
- 일기통관
- 찬타
- 소삼원
- 삼깡쯔
- 혼노두

3판 이상:

- 량페코
- 준찬타
- 혼일색
- 청일색

후로 감산:

- 삼색동순: 2 -> 1
- 일기통관: 2 -> 1
- 찬타: 2 -> 1
- 준찬타: 3 -> 2
- 혼일색: 3 -> 2
- 청일색: 6 -> 5

멘젠 한정:

- 리치
- 더블리치
- 일발
- 멘젠쯔모
- 핑후
- 이페코
- 량페코

탕야오는 후로 가능.

역패 표기:

- "역패"라는 단어는 표시하지 않는다.
- 예: 동, 남, 서, 북, 백, 발, 중
- 장풍과 자풍이 같고 그 풍패 커쯔/깡쯔가 있으면 더블동/더블남/더블서/더블북으로 표시한다.
- 연풍패 머리는 역이 아니고 부수만 4부.

도라 표기:

- 일반 도라 + 깡도라 + 적도라 = "도라 N"
- 우라도라 = "우라도라 N"
- 적도라와 깡도라는 별도 항목으로 표시하지 않는다.
- 도라만 있고 일반역이 0개면 화료 불가.

### 4.5 상황역 검증

명백한 모순은 선택 UI에서 막는다.

- 리치와 더블리치는 동시 선택 불가
- 후로 손패에서 리치/더블리치 불가
- 후로 손패에서 일발 불가
- 일발은 리치/더블리치 없으면 불가
- 해저로월은 쯔모 전용
- 하저로어는 론 전용
- 영상개화는 쯔모 전용
- 창깡은 론 전용
- 영상개화와 해저로월은 동시 불가
- 영상개화와 일발은 동시 불가
- 창깡과 하저로어는 동시 불가
- 창깡과 일발은 가능
- 창깡과 더블리치는 동시 불가
- 창깡은 성립 전의 가깡을 빼앗는 화료이므로 해당 깡으로 인한 깡도라/깡우라는 발생하지 않는다.
- 국사무쌍을 제외한 창깡은 순자 대기에서만 가능하다. MVP는 국사무쌍을 제외하므로, 창깡 ON인데 화료패가 순자를 완성할 수 없으면 계산불가로 표시한다.

자동 해제보다 "동시 선택 불가" 안내를 우선한다.

### 4.6 도라 계산

도라 표시패:

- 순서대로 모두 입력한다.
- 도라 표시패는 일반 34종만 표시한다.
- 적5는 표시패 입력 후보에 따로 둘 필요가 없다. 표시패로서 일반 5와 동일하기 때문이다.

우라 표시패:

- 리치/더블리치일 때만 입력한다.
- 도라 표시패 개수와 우라 표시패 개수를 같게 강제한다.

도라 순환:

- 수패 1->2, ..., 8->9, 9->1
- 풍패 동->남->서->북->동
- 삼원패 백->발->중->백

## 5. 부수 계산

### 5.1 일반형

기본:

- 기본부 20

화료 방식:

- 멘젠 론 +10
- 쯔모 +2
- 핑후 쯔모는 20부 예외

대기:

- 단기 +2
- 간짱 +2
- 변짱 +2
- 양면 +0
- 샤보 +0

머리:

- 삼원패 머리 +2
- 장풍패 머리 +2
- 자풍패 머리 +2
- 연풍패 머리 +4

몸통:

- 중장패 명각 +2
- 중장패 암각 +4
- 요구패 명각 +4
- 요구패 암각 +8
- 중장패 명깡 +8
- 중장패 암깡 +16
- 요구패 명깡 +16
- 요구패 암깡 +32

론으로 커쯔 완성:

- 닫힌 커쯔 후보라도 론 화료패가 그 커쯔를 완성한 경우 명각으로 취급한다.
- 삼암각 판정에서도 암각으로 세지 않는다.

쯔모로 커쯔 완성:

- 닫힌 커쯔는 암각으로 유지한다.

올림:

- 일반형은 합계 부수를 10단위 올림한다.
- 부가 부수가 없는 후로 론 형태는 "기본부 20 -> 부가 부수 없음 -> 최소 30부"로 표시한다.
- UI에는 "오픈 핑후"라는 표현을 쓰지 않는다.

### 5.2 치또이

- 항상 25부 고정
- 멘젠론/쯔모/단기/머리 부수 등 다른 부수를 붙이지 않는다.
- 10단위 올림하지 않는다.

### 5.3 5판 이상

- 5판 이상은 점수 계산에 부수가 필요 없다.
- 결과에는 "부수 무관"으로 표시한다.
- 부수 계산 세부 내역은 숨긴다.

## 6. 점수 계산

친/자:

- 자풍이 동이면 친
- 자풍이 동이 아니면 자

본장:

- 론: 기본 점수 + 본장 * 300
- 쯔모: 각자 지불액에 본장 * 100 추가
- 공탁은 입력/공유/결과 표시에서 제외하고 0으로 고정

등급:

- 5판: 만관
- 6~7판: 하네만
- 8~10판: 배만
- 11~12판: 삼배만
- 13판 이상: 카조에역만

절상만관:

- 없음
- 30부 4판, 60부 3판은 만관으로 올리지 않는다.

표기 예:

- 자 론 7700
- 친 론 11600
- 자 쯔모 2000/3900
- 친 쯔모 3900 all
- 본장 포함 총 수입 별도 표시

## 7. 최적 후보 선택

앱 내부는 가능한 해석 후보를 모두 계산한다.

비교 기준:

1. 최종 점수
2. 판수
3. 부수
4. 안정적 정렬 키

사용자에게 후보를 선택하게 하지 않는다.

동점 처리:

- 최고 점수가 같은 후보가 여러 개여도 기본 결과는 하나만 표시한다.
- 판수까지 같은 경우 "동점 해석 있음"을 표시한다.
- 데스크톱에서는 hover, 모바일에서는 탭으로 후보 목록 팝오버를 연다.
- 팝오버가 열린 상태에서 다른 곳을 클릭하면 닫힌다.
- 후보 목록은 이 경우에만 표시한다.

## 8. 오류 처리

오류는 가능한 한 전부 표시한다.

예:

- 패 수량 초과: 5만 계열 5장
- 적5만 2장
- 도라 표시패 미입력
- 리치/더블리치인데 우라 표시패 개수가 도라 표시패 개수와 다름
- 화료패가 최종 손패에 없음
- 화료형을 만들 수 없음
- 도라 제외 일반역 없음
- 후로 손패에서 리치 선택
- 영상개화와 해저로월 동시 선택
- 역만 손패

계산불가 표시는 결과 영역 최상단에 배치한다.

## 9. 화면 구성

모바일 우선 단일 페이지.

권장 흐름:

1. 빠른 조건 입력
   - 마지막 깡 직후 화료 여부
   - 론/쯔모 선택
   - 장풍/자풍
   - 본장
   - 상황역
2. 손패 입력
   - 현재 입력된 패 표시
   - 37종 패 버튼
   - 후보 선택 패널
   - 후로 토글
3. 화료패 선택
4. 도라/우라 표시패 입력
5. 계산 결과
   - 최종 점수
   - 등급
   - 역/판수
   - 도라/우라도라 개수
   - 부수와 세부 내역
   - 오류
6. 최근 기록/공유

결과 표시 순서:

1. 최종 점수
2. 등급 또는 부수/판수
3. 역 목록
4. 부수 계산
5. 본장 반영
6. 공유/기록

설명:

- 각 역/부수 항목 옆에 작은 도움말 버튼을 둔다.
- 데스크톱 hover, 모바일 탭으로 열고 닫는다.
- 긴 설명은 피하고, 계산에 필요한 의미만 표시한다.

## 10. 저장/공유

최근 기록:

- localStorage 사용
- 최근 20개 저장
- 전체 삭제 버튼
- 서버 전송 없음

공유 링크:

- URL fragment에 현재 계산 상태만 저장
- 최근 기록은 포함하지 않음
- 실행 가능한 코드를 저장하지 않음
- 파싱 실패 시 계산불가가 아니라 "공유 링크를 읽을 수 없음"으로 표시하고 빈 상태로 시작

## 11. 보안

정적 앱 기준.

- 백엔드 없음
- 외부 CDN 없음
- 외부 런타임 스크립트 없음
- eval 사용 금지
- innerHTML로 사용자 입력 삽입 금지
- URL fragment는 allowlist 스키마로만 파싱
- localStorage 데이터도 신뢰하지 않고 재검증
- 이미지 에셋은 프로젝트에 포함
- 작혼 공식 에셋 복제 금지
