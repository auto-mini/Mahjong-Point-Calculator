# 디자인 피드백 반영 메모

작성일: 2026-07-04

## 반영한 피드백

### 패 이미지

기존 후보 B는 CC0 타일 세트를 그대로 사용했지만 다음 문제가 있었다.

- 타일 몸체 여백이 작다.
- 심볼이 꽉 차 보여 모바일에서 답답하다.
- 흰 타일과 밝은 배경이 잘 구분되지 않는다.

수정 방향:

- FluffyStuff CC0 심볼은 유지한다.
- 타일 몸체는 앱용으로 다시 렌더링한다.
- 심볼 크기를 줄여 내부 여백을 확보한다.
- 타일 외곽, 측면색, 그림자를 추가한다.
- 배경 대비를 가진 B1/B2/B3 후보를 만든다.

새 후보:

- B1: 아이보리 베젤
- B2: 녹색 측면 강조
- B3: 작탁 배경 대비

현재 추천:

- 기본 앱 UI에는 B2가 가장 균형이 좋다.
- B1은 가장 무난하고 밝다.
- B3는 분위기는 좋지만 라벨/작은 UI 요소 대비를 더 조정해야 한다.

### 와이어프레임

기존 문제:

- `깡직후` 질문이 론/쯔모 옆에 있어 맥락이 이상했다.
- 패가 숫자/문자로 표시되어 실제 앱 방향과 달랐다.
- 후로 버튼이 후보 선택 버튼처럼 보여 의미가 불명확했다.

수정 방향:

- `깡 직후 확인`은 도라 입력 단계로 이동한다.
- 현재 손패, 패 선택, 몸통/머리 후보 모두 이미지 패로 표시한다.
- 후로 여부는 체크박스로 표시한다.
- 후보 선택 버튼은 후로 체크박스와 분리한다.

### UI 스타일

디자인은 임의 확정하지 않는다.

이번 산출물은 다음 3개 방향의 비교용이다.

- 시안 1: 차분한 계산기
- 시안 2: 작탁 대비
- 시안 3: 밝은 앱형

구현 전 사용자 승인 필요:

- 타일 후보 선택
- UI 스타일 방향 선택
- 색상 팔레트 선택
- 입력 화면의 정보 밀도 승인
