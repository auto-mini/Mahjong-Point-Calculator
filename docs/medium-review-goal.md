# Medium Review Goal

이 문서는 medium reasoning 세션에게 맡길 "수정 없는 이슈 탐색 루프" 지시문이다.
새 세션의 `GOAL`에는 이 문서를 참조하라고 짧게 적고, 실제 세부 지시는 이 문서를 기준으로 수행하게 한다.

## 목적

이 저장소의 리치마작 부수계산 웹앱 전체를 반복 리뷰하여, 이전 리뷰에서 발견되지 않은 새로운 이슈를 계속 찾는다.

이 세션의 역할은 수정이 아니라 이슈 수집이다.

## 절대 금지

- 코드를 수정하지 않는다.
- 파일을 생성/수정/삭제하지 않는다.
- 커밋하지 않는다.
- 푸시하지 않는다.
- 명백한 오류처럼 보여도 수정하지 말고 보고만 한다.
- 목표를 "고치기"로 바꾸지 않는다.

## 허용 작업

- 파일 읽기
- 코드 검색
- 테스트 실행
- 앱 실행
- 브라우저 확인
- 정적 분석
- 보안/상태복원/공유 링크 검토
- 발견한 이슈 보고

## 리뷰 범위

- 부수 계산
- 역 자동판정
- 도라/우라/깡도라 처리
- 창깡/영상개화/깡 직후 화료 여부 처리
- 론/쯔모, 오야/자, 본장 점수 계산
- 손패 입력 흐름
- 화료패 후보
- 후보군 생성
- 공유 링크 복원
- 최근 계산 기록
- 모바일 UI/터치 UX
- 접근성
- 보안상 위험
- 잘못된 상태 복원/비정상 URL 입력 방어
- 테스트 누락 가능성
- `docs/review-decisions.md`에 이미 기각/유지로 기록된 항목과의 충돌 여부

## 리뷰 루프

각 루프에서 다음을 수행한다.

1. 현재 저장소 상태를 기준으로 검토한다.
2. 먼저 `docs/review-decisions.md`를 읽고, 이미 유지하기로 한 항목을 같은 이유로 다시 제기하지 않는다.
3. 이전 루프에서 발견하지 않은 새로운 이슈를 최소 1개 찾으려고 노력한다.
4. 이슈는 반드시 현재 코드, 테스트, 화면 동작, 문서 중 하나에 근거해야 한다.
5. 단순 취향, 막연한 추측, "가능성 있음" 수준은 확신도 낮음으로 분리한다.
6. 같은 원인에서 나온 이슈는 여러 개로 부풀리지 말고 하나로 묶는다.
7. 계산 오류, 보안 문제, 접근성 실패, 실제 화면 깨짐은 `docs/review-decisions.md`와 관계없이 보고한다.
8. 각 루프가 끝날 때 이번 루프 신규 이슈 수와 연속 무이슈 횟수를 보고한다.
9. 새로운 이슈를 찾지 못한 리뷰가 연속으로 50회 발생하면 루프를 중단한다.

## 이슈 기록 형식

각 이슈는 아래 형식으로 기록한다.

```text
- ID:
- 제목:
- 분류: 계산 / 룰 / UI / UX / 접근성 / 보안 / 상태복원 / 공유링크 / 테스트 / 문서 / 기타
- 심각도: 높음 / 중간 / 낮음
- 확신도: 높음 / 중간 / 낮음
- 재현 방법:
- 기대 동작:
- 실제 동작 또는 의심 지점:
- 관련 파일/함수 추정:
- 왜 문제라고 보는지:
- docs/review-decisions.md와 충돌하는지:
- 사용자 의견이 필요한지:
- 수정 제안:
```

수정 제안은 작성해도 되지만, 실제 수정은 절대 하지 않는다.

## 중단 조건

다음 중 하나에 해당하면 루프를 중단한다.

- 사용자가 중지시킨 경우
- 새로운 이슈를 찾지 못한 리뷰가 50회 연속 발생한 경우
- 더 이상 의미 있는 검토 방향이 없다고 판단될 정도로 앱 전체를 충분히 검토한 경우

## 최종 보고

루프가 중단되면 발견한 모든 이슈를 취합하여 다음 기준으로 분류한다.

1. 명백한 오류로 보이는 항목
2. 사용자 의견이 필요한 항목
3. 오탐 또는 기각 추천 항목
4. 이미 `docs/review-decisions.md`에 의해 유지하기로 한 항목

최종 취합은 high 또는 xhigh 세션이 판단하기 쉽도록 작성한다.
중복 제거 전 원본 이슈와 중복 제거 후 요약을 둘 다 제공한다.

## 새 세션용 GOAL 문구

새 medium 세션에는 아래 문구를 `GOAL`로 넣는다.

```text
GOAL:
docs/medium-review-goal.md의 지시를 기준으로, 리치마작 부수계산 웹앱 전체를 반복 리뷰하여 새로운 이슈를 수집한다. 코드는 절대 수정하지 않는다. 명백한 오류처럼 보여도 보고만 한다. 새로운 이슈를 찾지 못한 리뷰가 50회 연속 발생하거나 사용자가 중지할 때까지 반복하고, 종료 시 발견 이슈를 문서 지시에 따라 분류해 보고한다.
```
