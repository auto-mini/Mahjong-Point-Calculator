# 버튼 확대 모드 교정 비교

- 촬영일: 2026-07-10
- 뷰포트: 320px 폭, 밝은 색상 모드
- `before-*`: 당시 공개 중이던 GitHub Pages 버전
- `after-*`: 이 저장소의 교정 후 `dist` 로컬 빌드

손패 화면에서는 확대 모드의 일반 동작 버튼을 최소 42px, 패와 부로 삭제처럼 밀집된 조작을 최소 40px로 맞췄다. 결과 화면의 부수 상세 펼침 버튼도 최소 42px로 맞추고, 키보드 포커스와 `aria-controls` 연결을 유지한다.

검증 시 320px에서 가로 스크롤이나 조작 버튼 간 겹침은 없었다. 같은 규칙은 Playwright로 320px, 360px, 390px, 430px에서 회귀 검증한다.
