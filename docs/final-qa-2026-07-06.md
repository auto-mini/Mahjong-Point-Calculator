## 모바일 렌더링 점검

Chrome headless로 다음 폭을 확인했다.

- 320px
- 360px
- 375px
- 390px
- 412px
- 430px

각 폭에서 작은 터치/큰 터치 모드를 모두 확인했다.

확인한 대표 화면:

- 1페이지: 화료/국 정보
- 2페이지: 손패 입력
- 3페이지: 도라/우라, 마지막 깡 직후 질문
- 4페이지: 계산 결과

확인 결과:

- 가로 overflow 없음
- 작은 터치 모드 핵심 버튼이 24px 미만으로 줄어드는 문제 없음
- 큰 터치 모드 핵심 버튼이 40px 미만으로 줄어드는 문제 없음
- 쯔모 상태에서는 `본인의 깡 직후에 화료했나요?`가 표시됨
- 결과 화면 샘플에서 총점/지불 표시가 정상 표시됨

## 선조치

큰 터치 모드에서 일부 상단 버튼과 선택 칩 높이가 38px대로 남아 있어 실제 큰 터치 모드로 보기 애매했다.

조치:

- 큰 터치 모드의 최근계산/작은 터치 버튼 최소 높이를 42px로 조정
- 큰 터치 모드의 장풍/자풍 칩 크기를 최소 42px로 조정
- 큰 터치 모드의 특정 상황역 칩 최소 높이를 42px로 조정
