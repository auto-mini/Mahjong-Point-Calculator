# 리치마작 부수계산기 구현/검증 요약

작성일: 2026-07-04
최종 갱신: 2026-07-10

## 구현 요약

- 백엔드 없는 정적 웹앱으로 리치마작 부수/점수 계산기를 구현했다.
- 1~4페이지 입력 흐름을 제공한다.
  - 화료 방식/국 정보/특정 상황역
  - 손패 및 화료패
  - 도라/우라/깡 직후 판정
  - 결과
- 일반역, 도라/우라도라, 부수, 본장 포함 점수를 자동 계산한다.
- 역만은 점수 계산 대상에서 제외하고 감지 시 계산을 중단한다.
- 최근계산은 `localStorage`에 최대 20개까지 저장하고, 복원 시 다시 검증한다.
- 공유 링크는 URL fragment `#s=` 기반이며, 최근계산 데이터는 포함하지 않는다.
- 사용자 입력은 `textContent`와 DOM 속성 기반으로 렌더링하며 `innerHTML`/`eval`을 사용하지 않는다.

## 기술 구성

- 정적 HTML/CSS/ES module.
- 실행: `scripts/run.ps1 preview`
- 테스트: `scripts/run.ps1 test`
- 정적 파일 검증: `scripts/run.ps1 verify`
- 빌드: `scripts/run.ps1 build`
- 공개 배포: GitHub Pages

## 주요 테스트 범위

- 도라 표시패 순환.
- 적5 정규화, 적도라, 일반 도라, 우라도라 계산.
- 동일패 5장 이상 및 적5 중복 방지.
- 손패 후보 생성과 적5 후보 처리.
- 화료패 후보, 창깡 화료패 후보 제한.
- 도라/우라 표시패 개수와 중간 빈칸 검증.
- 깡 직후 화료, 영상개화, 창깡의 도라/우라도라 적용 검증.
- 핑후쯔모 20부, 핑후론 30부.
- 치또이 25부 고정.
- 멘젠 론, 쯔모부, 대기부, 역패 머리, 커쯔/깡쯔 부수.
- 부가 부수 없는 후로 론 최소 30부 보정.
- 오픈 탕야오, 후로 혼일색 감산.
- 리치/더블리치/일발 제한.
- 도라만 있고 일반역이 없는 경우 차단.
- 3판 70부 이상 및 4판 40부 이상 만관 처리.
- 5판 이상 부수 무관 표시.
- 13판 이상 카조에역만 표시.
- 대삼원, 자일색, 녹일색, 청노두, 소사희, 대사희, 사암각, 구련보등, 사깡쯔 등 역만 감지와 계산 중단.
- URL fragment 공유 상태 생성/복원.
- legacy v1 공유 링크 복원.
- `localStorage` 최근계산 데이터 검증과 필터링.

## 배포 확인

- 공개 URL: `https://auto-mini.github.io/Mahjong-Point-Calculator/`
- 공개 산출물에서 `docs/`, `tests/`, `work/` 경로가 노출되지 않음을 확인했다.
- GitHub Pages는 `_headers`를 응답 헤더로 적용하지 않으므로 빌드 산출물에서 해당 파일을 제거했다.
- 공개 사이트의 CSP/Referrer 정책은 `index.html`의 meta 태그가 담당하며, 빌드 검증에서 요구 정책 전체가 정확히 유지되는지 확인한다.
- 로컬 미리보기 서버는 CSP, `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff` 응답 헤더를 별도로 적용하며 자동 테스트로 확인한다.
