# Review Decisions

이 문서는 전체 리뷰를 반복할 때 이미 검토했고 의도적으로 유지하기로 한 항목을 재지적하지 않기 위한 기록이다.
명백한 버그, 계산 오류, 보안 문제, 접근성 문제는 이 문서와 관계없이 다시 보고한다.

## 유지하기로 한 항목

### 도라 표시패 초과 입력 허용

도라 표시패가 실제보다 많이 입력되었는지는 앱이 확정할 수 없다.
깡 이력 전체를 입력받지 않기 때문이다.
따라서 도라 표시패 부족 입력은 막지만, 초과 입력은 허용한다.

다시 다룰 조건:
도라 표시패가 필요한 최소 개수보다 적은데도 계산되는 경우, 중간 빈칸이 있는데 통과되는 경우, 도라/우라 개수 규칙이 깨지는 경우.

### 하단 버튼 스크롤 허용

하단 버튼이 레이아웃 밖으로 깨지거나 입력 영역에 가려지는 것이 아니라, 스크롤로 접근 가능한 상태라면 허용한다.
모바일 입력 흐름에서는 고정 footer가 하단 콘텐츠를 가릴 수 있으므로 현재 구조를 유지한다.

다시 다룰 조건:
버튼이 화면 밖으로 렌더링되어 스크롤로도 접근할 수 없는 경우, 다른 요소에 가려져 터치할 수 없는 경우, 버튼 때문에 입력 내용이 잘리는 경우.

### 과거 공유 링크 호환성 낮은 우선순위

향후 공유 링크 포맷이 바뀌면서 과거 링크가 깨져도 허용한다.
개인 사용 MVP 단계에서는 구버전 호환성보다 구현 단순성과 현재 동작의 정확성을 우선한다.

다시 다룰 조건:
현재 버전에서 새로 생성한 공유 링크가 복원되지 않는 경우, 잘못된 링크가 앱을 깨뜨리는 경우, 악성 입력 방어가 약해지는 경우.

### O/X 후로 선택 화면 표시 유지

후로 여부 선택은 현재의 O/X 버튼 표시를 유지한다.
화면상 라벨을 더 길게 늘리지 않는다.
단, 접근성 라벨이나 내부 설명은 필요하면 유지해도 된다.

다시 다룰 조건:
O/X 터치 영역이 너무 작아 조작이 어려운 경우, 어느 쪽이 후로인지 앱 내부 라벨이나 접근성 정보에서도 구분되지 않는 경우.

### 지불 표시 형식 유지

현재의 간단한 지불 표시 형식을 유지한다.
불필요하게 긴 설명이나 표 형태로 바꾸지 않는다.

다시 다룰 조건:
점수 계산이 틀린 경우, 론/쯔모/오야/자별 지불 금액이 잘못 표시되는 경우, 표시 형식 때문에 금액을 오해할 수 있는 경우.

### 보조글자 대비 조정 유지

작은 보조 라벨과 안내문 색상은 현재처럼 약간 더 진하게 유지한다.
주요 제목, 점수, 결과 정보의 디자인 변화가 아니라 작은 글자의 가독성 보정이다.

다시 다룰 조건:
대비가 접근성 기준을 명확히 밑도는 경우, 보조글자가 배경과 구분되지 않는 경우, 전체 톤이 의도와 다르게 무거워지는 경우.

## 리뷰 시 참고

- 위 항목은 같은 이유로 반복 지적하지 않는다.
- 위 항목이라도 실제 화면 깨짐, 계산 오류, 보안 문제, 접근성 실패가 확인되면 다시 보고한다.
- 새로 결정한 보류/기각 항목이 생기면 이 문서에 추가한다.
