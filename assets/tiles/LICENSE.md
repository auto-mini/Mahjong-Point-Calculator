# Mahjong Tile Images

The tile images bundled under `assets/tiles/` are public-domain / CC0-style assets.
For the public-domain dedication, see:

https://creativecommons.org/publicdomain/zero/1.0/

The app currently renders the `assets/tiles/b2/` PNG set. These files are bundled
locally so the calculator does not need a remote image host at runtime.
